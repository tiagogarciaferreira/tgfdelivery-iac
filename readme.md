# Project TgfDelivery IAC

## Formatar o projeto
> tofu fmt -recursive

## Inicializar o projeto
> cd global/bootstrap/backend
> tofu fmt
> tofu init
> tofu validate
> tofu plan
> tofu apply

## Inicializar o environment(development)
> cd environments/development
> tofu fmt
> tofu init
> tofu validate

## Inicializar o environment(production)
> cd environments/production
> tofu fmt
> tofu init
> tofu validate
